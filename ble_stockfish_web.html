CYNUS + nước đi (API Lichess)

Nước đi lấy từ Lichess Cloud Eval — API công khai, miễn phí, không cần token: lichess.org/api (GET /api/cloud-eval?fen=…). Chỉ trả kết quả nếu vị trí đã có trong kho đánh giá cloud (ván lạ / hiếm có thể 404). Hạn mức: nên gọi tuần tự, tránh spam (429). Cần HTTPS + Chrome (Web Bluetooth).
